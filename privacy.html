Privacy Policy

WB SHOP BY Uploader / Creator Studio · Last updated 20 October 2026

This policy describes a locally operated development-stage desktop application and its static informational website. Actual third-party data practices depend on which optional integrations a user enables.

1. Who operates this project

WB SHOP BY Uploader / Creator Studio is independently maintained by its project operator. For contact information, see the operator's GitHub profile. Do not share passwords or tokens in public channels.

2. Website data

This website is made of static pages. It does not have a sign-in form, advertising trackers, analytics scripts or a server-side user database operated by this project. Your browser may still send standard requests (such as your IP address) to the GitHub Pages hosting service, which is operated by GitHub according to its own privacy practices.

3. Desktop application data

When configured on a user's computer, the desktop application may process product identifiers, titles, descriptions, prices, images, generated videos, publishing history, logs and preferences. If a user enables social integrations, it may also process account identifiers and OAuth access or refresh tokens provided by the connected service. This information is used to generate and manage media uploads and to keep local publishing records.

4. Local storage and security

Application settings, publishing history, generated files and authentication credentials may be stored in local files on the computer where the software runs. This website does not receive those files. Users should restrict access to their computer, back up needed data securely and avoid sharing configuration files such as .env or OAuth token files. Local storage may persist until the user deletes the application files or revokes access; it is not automatically erased by visiting this website.

5. Connected platform access

When a user explicitly authorizes a supported platform, the desktop application requests only the permissions needed for the selected integration. Depending on the chosen setup, it may send video media and captions to TikTok, YouTube, Instagram or Telegram, and upload video media to Cloudinary to obtain a temporary public HTTPS media URL required by another platform. Product data may be retrieved from configured product-data providers. Each provider processes the data it receives under its own terms and privacy policy. A public Cloudinary media URL may be accessible to anyone holding the URL for as long as it remains hosted.

6. Why data is processed

  • To connect an account at the user's request and maintain authorized access.
  • To assemble and preview product-based media content.
  • To upload selected content or perform enabled scheduled publishing tasks where supported.
  • To track successful, failed or uncertain uploads and avoid duplicate publishing.
  • To troubleshoot errors and preserve local configuration.

7. Data sharing

The desktop application may transmit media, profile identifiers and authorization tokens to the third-party services required for a selected feature. The static website itself does not provide a user-data sales or advertising service. It does not request users to paste tokens, passwords, customer lists or account credentials.

8. Data retention and deletion

Locally stored tokens, history and media remain on the user's computer until they are deleted or replaced. Users can revoke application access through the relevant connected platform's account settings and remove locally stored authentication files when access is no longer needed. Files already uploaded to a third-party platform may need to be deleted on that platform separately. The operator cannot guarantee deletion from independent providers.

9. Rights and requests

For privacy questions, access or deletion requests, contact the operator using a private contact option on the GitHub profile. Never disclose credentials, full OAuth tokens or sensitive personal information in a public repository issue. Where applicable, requests will be addressed under relevant privacy laws.

10. Policy updates

This policy may be updated when the desktop application, third-party integrations, hosting or data handling changes. A revised date will be displayed here.
